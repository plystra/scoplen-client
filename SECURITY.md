# Security policy

Report vulnerabilities in the Scoplen desktop client privately to `scoplen-security@plystra.com`. Include the affected version and platform, a description of impact, and a minimal reproduction when it is safe to share. Do not open a public issue for a vulnerability. The project follows a 90-day coordinated disclosure window as described in `scoplen-docs/14-security-engineering.md`.

No release of the client has been published yet, so no version is currently supported for security fixes.
